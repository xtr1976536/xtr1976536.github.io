# Personal Website Content Checklist

The first public-ready draft uses only information verified from the existing research files. Provide the items below before the final application version is published.

## Identity and contact

- Preferred English name and exact Chinese name
- Professional email address to display publicly
- Expected graduation month and year
- Current city, if different from Guangzhou
- Professional headshot, ideally a square JPG or PNG of at least 800 x 800 pixels

## Academic profiles

- Google Scholar profile URL
- ORCID URL
- Optional LinkedIn URL

## Education

- Exact degree title
- Expected graduation date
- Major ranking or percentile, if favorable
- Selected advanced courses and grades, if useful
- Scholarships, honors, competitions, or academic awards

## Publications and manuscripts

For every item that should appear publicly:

- Exact English title
- Complete author list in publication order
- Your author position and contribution
- Status: published, accepted, under review, preprint, manuscript, or work in progress
- Venue and year, when applicable
- DOI, arXiv, SSRN, PDF, and code links, when public
- A two- or three-sentence plain-language summary

## Research experience

- Supervisor names and affiliations
- Project dates
- Your concrete contribution to each project
- Methods used and results obtained
- Public code, data, posters, or slides

## Skills

- Programming languages and realistic proficiency
- Mathematical and statistical software
- Machine learning libraries
- English test scores, when available
